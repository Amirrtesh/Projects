# 🔐 Random Password Generator

A simple **Python Random Password Generator** that creates passwords of a user-specified length using letters, numbers, and special characters.

## ✨ Features

* 🔑 Generates random passwords
* 🔢 Supports custom password length
* 🔤 Uses uppercase and lowercase letters
* 🔢 Includes numbers
* 🔣 Includes special characters
* 🐍 Built with Python

## 🛠️ Technologies Used

* 🐍 Python
* 🔢 NumPy
* 🐼 Pandas

## ⚙️ Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## 🚀 How to Run

Run the Python program:

```bash
python main.py
```

Enter the desired password length when prompted.

### Example

```text
how many digit password want to be excuted: 12
Random Password: a@7Kp!2xQ#9Lm
```
