# 🖼️ Image2Prompt AI

### Deep Learning-Based Automatic Prompt Generation

Image2Prompt AI is a deep-learning-based application that automatically converts an uploaded image into a detailed AI prompt.

## 🚀 Features

* 🧠 BLIP Vision-Language Model
* 🖼️ Image understanding
* 🎨 Dominant color detection
* 💡 Lighting and contrast analysis
* 📐 Image geometry and orientation analysis
* 🎯 Basic composition analysis
* ✨ Automatic A-Z prompt generation
* 📥 Prompt download
* 🌐 Streamlit web interface
* 🚀 GPU acceleration when CUDA is available

## 🛠️ Technologies Used

* Python
* Streamlit
* PyTorch
* Hugging Face Transformers
* BLIP
* NumPy
* Pillow

## ▶️ How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

The application will open in the browser.

## 🎯 Objective

The objective of Image2Prompt AI is to reduce the manual effort required to create detailed AI prompts from images by automatically analyzing visual information and converting it into a structured textual prompt.
